# Аудит WG Monitor — 2026-11-27

## Критические

### DEPLOY-01: rollback backend-update-runner не перезапускает бэкенд
- **Файл**: `cmd/backend/backend_update_cli.go`
- **Проблема**: после неудачного рестарта бинарник откатывается, но старый бэкенд не запускается; pending-запрос остаётся и запускается снова каждые две минуты.
- **Решение**: перезапускать откатанный бинарник и завершать неудачный pending-запрос после записи статуса.
- **Статус**: [x]

## Высокие

### ALERT-01: «Тише на час» действует слишком долго
- **Файл**: `internal/backend/db/state.go`
- **Проблема**: `silenced_until` сравнивается с cutoff вместо текущего времени.
- **Решение**: разделить cutoff последней отправки и текущий момент.

### DEPLOY-02: auto-update timer некорректен для Docker/Pi
- **Файл**: `cmd/deploy/backend_remote_update.go`
- **Проблема**: отсутствуют подготовка unit directory, XDG runtime, linger и ветка root/system systemd.
- **Решение**: выбрать user/system unit по пользователю и подготовить окружение.
- **Статус**: [x]

### DEPLOY-03: swap бинарника может завершиться без rollback
- **Файл**: `cmd/deploy/backend_binary.go`
- **Проблема**: ошибка backup игнорируется, ошибка chmod после mv не откатывается, shell-пути не экранируются.
- **Решение**: проверять backup, экранировать пути и откатывать частично выполненный swap.
- **Статус**: [x]
