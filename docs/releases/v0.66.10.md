# v0.66.10

## Deploy and recovery

- Failed backend self-updates now restore and restart the previous binary, consume failed pending requests, and no longer retry the same broken update every two minutes.
- Docker/Pi update timers handle root and non-root systemd layouts, runtime directories, lingering sessions, quoted paths, and failed binary swaps safely.
- Rollout state is not advanced when SQLite fails to record an observed target.
- Secret imports roll back mixed writes, and temporary files use unpredictable exclusive names.

## Alerts

- The one-hour silence window is compared with current time instead of the realert cutoff.
- Ambiguous Telegram timeouts are no longer resent as duplicate alerts or recovery replies, while mixed timeout/rate-limit errors still apply Telegram backoff.
- Mobile reminders can use a cadence shorter than the default realert interval.
- Long alert cards stay within Telegram's message limit.
- Link-repair cooldown handling consistently retains backup state and starts move-only recovery.

## Mini App

- Timeline requests ignore stale responses after switching router or filter.
- Confirmation sheets announce themselves as modal dialogs, contain keyboard focus, and return focus to their opener.
- Cancelling a fleet rollout shows busy and failure states instead of silently swallowing errors.
- Selected, warning, and conflict states preserve keyboard visibility without thick one-sided accent borders.

## Audit

This release includes the complete deploy, alert, recovery, and Mini App audit fixes documented in `docs/project-review-2026-11-27.md`.
