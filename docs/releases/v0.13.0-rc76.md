# v0.13.0-rc76

## English

### Telegram Menu Reliability

- Backend startup now calls `setChatMenuButton` with Telegram's `commands` button, so supported clients show the blue `Menu` button near the message input.
- Router-topic welcomes, `/menu`, `/keyboard`, topic creation, topic recreation, and admin "Revive topics" now send two menu surfaces:
  - a bottom `ReplyKeyboardMarkup` that mobile clients keep near the input bar;
  - a visible inline fallback menu under the message for Desktop and clients that hide reply keyboards.
- Tests now cover the commands menu button and the two-message topic menu recovery flow.

## Русский

### Надежность Telegram-меню

- При старте backend теперь вызывает `setChatMenuButton` с Telegram-кнопкой `commands`, чтобы клиенты показывали синюю кнопку `Menu` рядом с полем ввода.
- Приветствия топиков, `/menu`, `/keyboard`, создание топиков, пересоздание топиков и админское "Оживить топики" теперь отправляют две поверхности меню:
  - нижнюю `ReplyKeyboardMarkup`, которую мобильные клиенты держат рядом с вводом;
  - видимое inline-меню под сообщением как fallback для Desktop и клиентов, которые прячут reply keyboard.
- Тесты покрывают кнопку commands menu и двухсообщенческое восстановление меню в топике.
