# v0.66.8

- The Mini App distinguishes a failed VPN tunnel from a missing or stale measurement. A stopped tunnel selected by routing policy remains visible as a failed route. A backup needs a recent successful check to appear ready.
- The tunnel count matches checks to the IDs in the router inventory. An unrelated check can no longer make an unchecked tunnel appear healthy. Statuses age while the screen stays open.
- The agent retains its last inventory when AWG Manager returns an incomplete response and uses each tunnel’s own latency measurement time.
- Mobile status text is easier to read. Installation and reinstallation forms explain how the server selects the agent version.
- Fleet rollout handling and release verification have been tightened. Go and Mini App dependencies have been refreshed.
