# v0.13.0-rc36

## VPS Sync

- `[6] Sync from VPS` now restores a wider non-secret metadata pool for another operator PC.
- Agent sync now includes last deploy time, deploy mode, AWG Manager URL/auth mode, and `expected_mac` in addition to SSH coordinates, arch, versions, rollout ring, and pending deploy state.
- `expected_mac` is guarded: an empty local pin is filled from VPS, but a conflicting local pin is preserved and reported.
- Machine-local `preferred_iface` and secrets are still not synced through the wizard API.
