# v0.13.0-rc23

## Deferred AWG Manager deploy

- Added a smart offline-router deploy path for AWG Manager/KeenDNS installs.
- When the public AWG Manager URL is unreachable from the VPS, the wizard can queue a root-only deferred job on the VPS instead of failing the flow.
- The VPS installs a small `wg-monitor-deferred-awgm.timer` that checks queued jobs every two minutes.
- When the router comes online, the job:
  - reads AWG Manager `/api/system/info`;
  - creates the agent enrollment locally through `127.0.0.1:8080`;
  - bootstraps the agent through AWG Manager terminal;
  - writes deploy metadata back to `/v1/wizard/agents/{nickname}`;
  - saves the raw agent token as a root-only `.token` file next to the completed job.

## Operator UX

- Existing live AWG Manager installs still work the same way.
- Transient AWG Manager failures now offer a deferred deploy prompt for public VPS-routed URLs.
- Local `wizard.toml` marks the agent as pending with the target version while the VPS waits for the router.
