# v0.13.0-rc115

## Release Focus

Hotfix for AWG Manager template loading on routers that return `/api/presets`
inside the standard `success/data` envelope.

## Changes

- AWG Manager presets now load from both supported response shapes:
  `{"presets":[...]}` and `{"success":true,"data":{"presets":[...]}}`.
- Template lookup now fails loudly on `success:false` instead of silently
  rendering an empty template list.
- Added a regression test for the live AWG Manager envelope shape observed on
  `testkeen`.
