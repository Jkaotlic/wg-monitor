## Deploy UX

- `[2] Update components` now keeps recovery in the same flow for agents that cannot safely use `self_update`.

- Pull-flow token/cmdloop hints no longer send the operator to another menu item; the wizard can offer AWG Manager re-enroll from the current update flow.
