# v0.66.1

## Release Focus

This release makes tunnel state explainable in the mini app and hardens fleet
operations so an operator can see both the verdict and the evidence behind it.

## Highlights

- Tunnel cards now distinguish the bot verdict, AWG Manager state, freshness,
  policy path and HydraRoute evidence instead of collapsing them into one badge.
- The tunnel screen includes a compact incident story and clearer stale,
  direct-path and evidence-mismatch states.
- Long mini-app screens are split into lazy-loaded chunks, reducing the initial
  JavaScript payload without changing navigation.
- Agent rollout state is persisted in SQLite, uses a real canary observation
  phase and resumes conservatively after backend restarts.
- Operator actions are recorded in a public-safe operation journal without
  exposing internal command or operation identifiers.
- Report cancellation and command completion are idempotent, including retries
  after uncertain network outcomes.
- The deployment wizard can install a hardened external readiness probe on a
  separate host; provider-specific notification credentials remain explicit.

## Security and Compatibility

- `golang.org/x/net` is updated to `v0.62.0` to resolve `GO-2026-6860`.
- `golang.org/x/crypto` is updated to the first fixed revision reported by the
  release vulnerability scan.
- Database changes are additive (`CREATE TABLE IF NOT EXISTS`) and are included
  in the encrypted small-backup allowlist.
- Existing `v0.65.0` agents remain compatible; this release does not require a
  fleet-wide agent update just to use the new backend and mini-app views.
- Release assets, checksums, signature and SBOM are produced by the standard
  GitHub Actions release workflow.
