# v0.13.0-rc116

## Release Focus

Hotfix and UX polish for adding routes from AWG Manager templates.

## Changes

- AWG Manager templates are now shown as compact paged Telegram buttons instead
  of a truncated one-screen list.
- Template pages are rendered from a short-lived backend catalog cache, so
  next/previous page navigation does not re-query the agent.
- Route apply now refreshes AWG Manager routing before creating the rule.
- Route target resolution uses `/api/routing/tunnels` as the canonical source
  for bind iface values, while preserving tunnel aliases from `/api/tunnels/get`
  for rebind compatibility.
