# v0.13.0-rc24

## Operator recovery

- Added a service-menu flow to bind a fresh/secondary operator PC to the current VPS.
- New CLI aliases: `adopt-backend`, `adopt-vps`, and `bind-backend`.
- The flow asks for current VPS SSH/domain data, reads `/etc/wg-monitor/wizard-token.txt` over SSH, stores `WIZARD_TOKEN`, verifies backend health best-effort, then runs `sync-vps`.

## Mobile flap tolerance

- Mobile routers now use a separate `mobile_fail_threshold` before HARD alerts.
- Mobile realert reminders now use `mobile_realert_every_sec`, independent of the static/router default.
- Backend defaults and the generated backend config now wait 30 minutes before the one-shot mobile sleep info-card.
- Existing aggressive `mobile_sleep_after_sec` values below 1800 are clamped when mobile lifecycle is enabled.
