# v0.13.0-rc25

## VPS adoption UX

- The VPS SSH auth prompt now accepts a pasted private-key path directly.
- If the operator enters something like `C:\Users\Anex\.ssh\id_ed25519_vps_main` in the `password/key` prompt, the wizard treats it as `key` auth and uses that path instead of falling back to password auth.
- The service-menu hint for current VPS adoption is now in Russian.
