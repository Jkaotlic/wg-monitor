# v0.13.0-rc22

Release focus: protect deploy updates from stale GitHub release listings and route public AWG Manager probes through the VPS.

## Highlights

- Prevented the wizard from selecting a release older than its own build when the unauthenticated GitHub releases API returns stale data.
- Added a direct tag lookup fallback for the running wizard version so a freshly downloaded RC does not try to downgrade backend or agents.
- Moved public AWG Manager `system_info` probing into the existing VPS-side relay path, matching the terminal bootstrap flow.
- Preserved API-key to login/password fallback when AWG Manager returns HTTP 401 through the relay path.

## Verification

- `go test ./... -count=1`

## Assets

The release publishes deploy binaries for Windows, macOS, and Linux, plus backend, CLI, router agent binaries, checksums, and SBOM.
