# v0.13.0-rc75

## English

### Telegram Menu And Operator UX

- Added a shared Telegram menu registry for router-topic buttons, slash commands, admin panel rows, and operator help.
- The default bot command menu is now operator-safe and includes `/amnezia`, `/hidemy`, and `/menu`.
- Admin commands are registered separately in admin scopes, so `/panel` and topic-maintenance commands do not pollute operator command discovery.
- `/menu` is a visible-menu recovery alias for `/keyboard`.
- The admin panel "revive topics" action re-sends the current visible menu to all router topics and reports sent, failed, and skipped-no-topic counts.

### Router Operations

- Route panels now request fresh live route state after route changes instead of leaving operators with stale cached tunnel information.
- Maintenance and route notifiers enqueue fresh follow-up status after state-changing actions.
- Amnezia Premium and HideMy.name generated configs now request `nativewg` on import and replacement.
- Per-tunnel restart now performs `interface down`, waits briefly, then performs `interface up`.
- Tunnel panels hide unsafe enable/disable/restart/delete controls when the router did not report an NDMS interface name.

## Русский

### Telegram-меню и UX оператора

- Добавлен общий registry Telegram-меню для кнопок в топиках роутеров, slash-команд, строк admin panel и операторской справки.
- Default command menu теперь безопасен для оператора и содержит `/amnezia`, `/hidemy`, `/menu`.
- Админские команды регистрируются отдельным admin scope, поэтому `/panel` и команды управления топиками не смешиваются с операторскими командами.
- `/menu` работает как alias восстановления видимого меню, аналогично `/keyboard`.
- Кнопка "оживить топики" в admin panel заново присылает актуальное видимое меню во все топики роутеров и показывает счётчики отправлено / ошибок / без топика.

### Операции на роутерах

- Панель маршрутов после изменений запрашивает свежий live route state, чтобы оператор не видел устаревшую информацию о тоннелях.
- Notifier'ы маршрутов и обслуживания ставят свежий follow-up status после действий, которые меняют состояние.
- Конфиги Amnezia Premium и HideMy.name при импорте/замене теперь явно создаются в `nativewg`.
- Перезапуск конкретного тоннеля теперь делает `interface down`, короткую паузу и затем `interface up`.
- Панель тоннелей скрывает опасные enable/disable/restart/delete controls, если роутер не прислал NDMS interface name.
