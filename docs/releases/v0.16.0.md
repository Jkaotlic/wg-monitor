# v0.16.0

## Release Focus

The mini app moves to its own design system, and a broken feature nobody had
noticed gets fixed.

## Changes

### Design system

- One theme, dark, on purpose: the app is opened at night and in a car. Theme
  selection, the `themeChanged` subscription and the now-dead
  `getColorScheme`/`onColorSchemeChanged` are gone. A test forbids a second
  set of values in CSS so the switch cannot creep back.
- Tokens come from the project's Claude Design design system under the names
  its own lint config lists: `--bg --surf --surf2 --ink --dim --line --line2
  --sig --ok --warn --bad`, plus `--led-off` and `--on-sig`. The former names
  (`--page`, `--surface`, `--text`, …) stay as aliases while screens migrate
  one at a time; a test keeps an alias from growing a value of its own.
- IBM Plex Sans for prose, IBM Plex Mono for data — interface names, geo tags,
  timestamps: everything the operator checks against the router by eye.
- Contrast recomputed across every text token on all three surfaces: the
  smallest margin is 5.7:1 against the required 4.5. The mockup understated
  its own numbers.
- Secondary buttons stopped being painted in the signal lime. Lime means "the
  line is alive" and marks the one main action of a screen; outlining "1 hour",
  "24 hours" and "got it" with it made it mean nothing.
- Component layer in place: state tag, pill, stat tile, hero, data row, chain
  link, nav card.

### Router API

- **`pingcheck_toggle` was hitting an endpoint that no longer exists.**
  `POST /api/pingcheck/toggle` returns 404 on awg-manager 2.17.2; the
  replacement is a per-tunnel pair, `/api/tunnels/pingcheck` and
  `.../pingcheck/remove`. Until now the action fell through to
  `ndmc interface <ndms_name> ping-check` — and opkg tunnels have no
  `ndms_name` at all, so for half the fleet's tunnels the feature was broken
  outright, and the error blamed ndmc rather than the missing endpoint.
  The ndmc path stays for older builds but now says plainly when there is no
  interface name to address instead of running with an empty one.
