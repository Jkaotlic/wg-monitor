# v0.13.0-rc26

## Deploy safety

- Backend health checks now tolerate the short listener startup window after `systemctl start`, avoiding false `127.0.0.1:8080` connection-refused failures.
- Static-agent pull updates now preflight `/v1/wizard/agents` heartbeat before enqueueing `self_update`.
- If a static agent is stale, missing, or looks token-corrupt, the wizard stops before enqueue and points to `repair-agent-token --agent <nick>` / router re-enroll.
- Pull-flow ack timeouts now include heartbeat/token recovery guidance instead of a generic long-poll hint.
