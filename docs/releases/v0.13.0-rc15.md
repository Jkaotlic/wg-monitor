# v0.13.0-rc15

Release focus: deployment wizard polish, AWG Manager router bootstrap, and more reliable tunnel health reporting.

## Highlights

- Reworked the deploy wizard into task-oriented sections: backend, updates, routers, VPS migration, doctor, sync, and service tools.
- Replaced the default router deployment path with AWG Manager/KeenDNS + Entware bootstrap.
- Added clearer FAQ/help text next to wizard actions.
- Added component install version and deploy timestamp rows in the wizard header.
- Quieted startup VPS sync for normal temporary network failures; auth failures still warn clearly.
- Improved tunnel health normalization so disabled PingCheck does not falsely hard-fail an otherwise alive tunnel.
- Hardened wizard menu rendering so borders stay aligned with long versions and status rows.

## Assets

The release publishes deploy binaries for Windows, macOS, and Linux, plus backend, CLI, router agent binaries, checksums, and SBOM.

GitHub release: <https://github.com/Jkaotlic/wg-monitor/releases/tag/v0.13.0-rc15>
