# v0.13.0-rc34

## Deploy safety

- `[2] Update components` can now put stale static-agent updates into a VPS-side waiting job instead of failing after the heartbeat preflight.
- The VPS installs `wg-monitor-deferred-agent-update.timer`, which waits for a fresh agent heartbeat, enqueues `self_update`, and keeps the job until `/v1/wizard/agents` confirms the target version.
- Deferred agent-update jobs store only wizard auth plus the target version, not raw agent enrollment tokens.
