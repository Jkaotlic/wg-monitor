# v0.13.0-rc49

## Self-Hosted Amnezia

- Added backend-managed self-hosted Amnezia VPS entries stored in `/var/lib/wg-monitor/amnezia-selfhosted.json`.
- Added admin-only Telegram command `/selfhosted` to list, add, update, enable, disable, and delete self-hosted Amnezia VPS entries without editing `backend.yaml`.
- The Amnezia Premium panel now shows one "Self-hosted ... .conf" button per enabled self-hosted VPS.
- Self-hosted config issuance remains admin-only; router operators cannot issue configs from self-hosted VPS entries.
