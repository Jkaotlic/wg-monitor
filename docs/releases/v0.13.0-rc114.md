# v0.13.0-rc114

## Release Focus

Operator UX and route correctness for AWG Manager driven routing.

## Changes

- Self-hosted Amnezia VPS entries now capture SSH password alongside SSH host, port, user, and endpoint fields.
- The "check via VPN" flow resolves the tunnel currently used for routing instead of taking the first tunnel-like entry.
- NDMS and HR-Neo route snapshots/rebinds preserve direct/WAN routes and do not move provider/direct HR-Neo policies into tunnel counts.
- Route add flow can load AWG Manager templates from `/api/presets`, show them as Telegram buttons, then apply the selected template through the normal preview and confirm flow.
- Template application is covered for both NDMS and HR-Neo: selected templates bind to the chosen routing interface, not the first interface in the list.
